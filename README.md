# aurav-cabina-at802

Cabina del Air Tractor AT-802 en WebXR (Three.js) para AURAV. Prototipo de uso interno.

- `cabina.glb`: interior del AT-802 Fire Boss freeware para FSX (Flight Sim Nation / rikoooo), convertido con `herramientas/mdl2glb.py`.
- Pendiente: completar los instrumentos (en FSX se dibujaban en vivo) con recortes de fotos 360 reales de la cabina.
- Abrir `index.html` con un servidor local o por GitHub Pages; en Quest, botón «Entrar en VR».
